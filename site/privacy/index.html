隱私權政策

JarvisVoice 是 Runvo LLC（以下稱「我們」）做的 macOS 選單列語音輸入小程式，原始碼以 MIT 授權公開在 GitHub。這份政策說明你用 JarvisVoice 時，哪些資料只留在你的 Mac、哪些會送出去、送給誰，以及你可以怎麼管理。

生效日期與最後更新：2026 年 11 月 18 日

一、適用範圍

  • 本政策適用於 JarvisVoice App、JarvisVoice 帳號（含點數），以及 jarvis-voice.com 網站。
  • 你自己選用的第三方服務（例如用自己的 key 連的 OpenAI），以及網站上連到的其他網站，不適用本政策，請看各自的隱私權政策。

二、三種用法，資料去處不同

JarvisVoice 的轉寫與 AI 整理有三種用法，你在選單裡選哪一種，資料就走哪一條路：

  1. 本機辨識（預設）：在你的 Mac 上用 SenseVoice（sherpa-onnx）辨識，聲音不離開你的 Mac。辨識模型第一次使用時從 GitHub 下載。
  2. 自己的 key：聲音與要整理的文字，直接從你的 Mac 送到你選的服務，不經過我們，我們也收不到。詳見第五條。
  3. JarvisVoice 帳號：不用 key，在 App 裡買點數。聲音與要整理的文字送到我們的伺服器，由伺服器轉給 AI 模型供應商處理後回傳結果。詳見第六條。

轉寫與 AI 整理可以分開選，例如轉寫用本機辨識、AI 整理用自己的 key。

三、只存在你 Mac 上的資料

下面這些資料只存在你的 Mac，我們收不到：

  • 歷史（轉寫與整理後的文字）、詞彙、設定：存在你家目錄的 ~/.voice-dictation 資料夾。
  • 自己的 key、JarvisVoice 帳號的登入 token：存在 macOS 鑰匙圈。
  • 聲紋（「只聽我的聲音」，預設關）：在你的 Mac 上計算，存在你的 Mac。
  • 偵錯音檔（預設關）：打開才會把錄音存在你的 Mac。
  • 本機辨識模型：下載後存在你的 Mac。

四、會送出去的內容

不用本機辨識、或打開 AI 整理與語音指令時，會送出下列內容。送到哪裡，看你用自己的 key（第五條）還是 JarvisVoice 帳號（第六條）：

  • 聲音：只送有人聲的片段。收音一直開著，旁邊有人講話也會一起送去轉寫；開會、看影片時可以從選單按「暫停收音」。
  • AI 整理（開著時）：你講的話，加上游標前後各約 400 字、選取的字、視窗裡看得到的字（最後約 1,500 字）、App 名稱、視窗標題、網址。
  • 語音指令（第三層，開著時）：你講的指令，以及畫面上按鈕、連結、輸入框的名稱。

畫面上的字可能包含你正在看的信件、對話或文件內容。處理敏感內容時，可以從選單關掉 AI 整理、語音指令，或暫停收音。

五、使用自己的 key

  • 轉寫：聲音直接送到你選的轉寫服務（OpenAI，或平行沙盒 ParallelSandbox）。
  • AI 整理：要整理的文字與上下文，直接送到你選的 AI（OpenAI、DeepSeek 或 Anthropic Claude）。OpenAI 與 Anthropic 的主要伺服器位於美國，DeepSeek 的伺服器位於中國。
  • 語音指令：每一步由決策器判斷，可能是 TypeSafe 的 Jev（用你自己的 key），或你選的 AI。

這些資料由你直接跟那家服務往來，不經過我們，我們也收不到。那家服務怎麼處理你的資料，依它的服務條款與隱私權政策。你的 key 存在 macOS 鑰匙圈，只用來呼叫你選的服務。

六、使用 JarvisVoice 帳號

登入

  • 從選單「登入 JarvisVoice…」，用瀏覽器登入並按允許（OAuth）。這個登入的權限只限語音輸入：JarvisVoice 看不到、也改不了你帳號裡的其他資料。
  • 登入 token 存在你 Mac 的鑰匙圈，不寫進設定檔。從選單登出時，這個 token 會一起撤銷。
  • 帳號可以用 Google、Apple、GitHub 或 email 登入。用 Google、Apple、GitHub 登入時，我們只拿登入需要的基本資料：你的名字、email，以及對方有提供的頭像（Google 是 openid、email、profile 這三項權限）。
  • 這些資料只用來建立、識別你的帳號，以及顯示目前登入的是誰；不用在廣告，不賣，也不分享給第三方（第九條列的情況除外）。

聲音與文字怎麼處理

  • 聲音（有人聲的片段）與要整理的文字、上下文（第四條列的內容），送到我們的伺服器 app-api.jarvis-voice.com。伺服器轉給 AI 模型供應商（例如 OpenAI）處理轉寫與整理，再把結果回傳給你的 Mac。我們使用各供應商的 API 服務與其 API 條款。
  • 你的聲音與文字，我們只在處理這次請求、計費與防止濫用所需的範圍內使用，不會用來訓練模型，也不會用在其他用途。
  • 照用量扣點數：轉寫照錄音的分鐘數，AI 整理與語音指令的判斷照用量。

我們保存的帳號資料

  • 你的 email（用來識別你的帳號、跟你聯絡）。
  • 你的名字與頭像（用 Google、Apple、GitHub 登入時由它們提供，用來顯示目前登入的是誰）。
  • 點數餘額與用量紀錄。
  • 點數購買的付款紀錄（見第七條）。

七、購買點數與付款（Stripe）

  • 在選單「購買點數…」選好點數包，會用瀏覽器打開 Stripe 的付款頁付款。
  • 卡號等付款資料由 Stripe 處理，我們不經手、也不保存你的卡號。我們只收到付款結果，用來把點數加進你的帳號，並保存付款紀錄。
  • Stripe 怎麼處理你的付款資料，依 Stripe 隱私權政策。

八、我們不做的事

  • JarvisVoice 沒有分析、追蹤或廣告 SDK，不會回報你的使用情形。
  • 檢查更新只連 GitHub，不送使用資料。下載辨識模型、檢查更新時，GitHub 依它自己的隱私權政策處理連線資料。
  • jarvis-voice.com 網站沒有放分析或追蹤程式。
  • 我們不出售你的個人資料。

九、與第三方共用

未經你同意，我們不會出售或分享你的個人資料給第三方。只有下列情形會提供：

  • 為了提供你用的功能：使用 JarvisVoice 帳號時，聲音與文字送給 AI 模型供應商處理（第六條）；購買點數時由 Stripe 處理付款（第七條）。
  • 經過你的同意。
  • 法律明文規定。
  • 為了免除你生命、身體、自由或財產上的危險。
  • 你的行為違反服務條款，或可能損害本服務、其他使用者或任何人的權益，為了辨識、聯絡或採取法律行動而有必要。

我們委託廠商協助處理資料時，會要求對方遵守保密義務，並負起監督責任。

十、資料保護

  • App 與我們伺服器之間的連線以 TLS 加密。
  • 只有經過授權的人員能接觸帳號資料，並負有保密義務。
  • 你的 key 與登入 token 存在 macOS 鑰匙圈，不寫進一般檔案。

十一、資料保存

  • 你 Mac 上的資料：一直留著，直到你自己刪除（見第十二條最後一段）。
  • 帳號資料（email、名字與頭像、點數餘額與用量紀錄、付款紀錄）：帳號存在期間保存。刪除帳號後，我們從營運系統刪除；備份中的副本，在備份週期屆滿後一併清除。依法需要保留的付款與點數交易紀錄除外。
  • 你的聲音與要整理的文字：依第六條，只在處理請求、計費與防止濫用所需的範圍內使用。

十二、刪除帳號

JarvisVoice 帳號是 Runvo LLC 的會員帳號。刪除帳號會刪除整個帳號：你用同一個帳號使用的 Runvo LLC 其他產品，帳號與資料也會一起刪除。

怎麼刪除

  • 到 app.jarvis-voice.com 登入，按「刪除我的帳號」，確認後刪除。
  • 無法登入時：用你註冊時的 email 寄信到 runvo.tech@gmail.com，主旨寫「帳號刪除申請」。我們會在合理期間內處理。

會刪掉什麼

  • 你的帳號、登入身分與使用權限，包括同一個帳號在 Runvo LLC 其他產品的帳號。
  • 你在這些產品裡的內容、個人資料、剩下的點數、用量紀錄、設定與偏好。

依法需要保留的付款與點數交易紀錄除外。刪除後無法復原；備份中的副本，在備份週期屆滿後一併清除。

你 Mac 上的資料

刪除帳號不會動到你 Mac 上的資料。要清掉的話：從選單登出 JarvisVoice、刪除 JarvisVoice App 與 ~/.voice-dictation 資料夾；自己的 key 可以在「鑰匙圈存取」裡刪除。

十三、兒童

JarvisVoice 不是為未滿 13 歲的兒童設計的，我們不會刻意蒐集兒童的個人資料。如果你發現有兒童在使用 JarvisVoice 帳號，請寫信告訴我們，我們會刪除相關資料。

十四、政策修改

我們可能依需要修改這份政策。修改後的內容會刊登在本頁，並更新上面的日期。
